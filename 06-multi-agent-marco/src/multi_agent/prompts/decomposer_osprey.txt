## Instructions
Based on the Phase 1 evidence above, determine what information is STILL NEEDED to confidently answer the question. Generate sub-questions targeting ONLY the gaps.

**For bridge questions**: If Phase 1 identified the intermediate entity (e.g., found "The film was directed by John Smith"), create sub-questions that directly use that entity — do NOT generate a sub-question to re-find what was already found. **For comparison questions**: If Phase 1 retrieved data for one entity already, focus sub-questions on the other entity or the missing attribute.

**For single_hop questions**: Generate a single sub-question as usual.

## Question Types
1. **comparison** — Compares ≥2 entities; sub-questions run in parallel (no depends_on)
2. **bridge** — Information chain; later sub-questions use [answer_N] placeholders
3. **single_hop** — Directly answerable; one sub-question

## Output Format
Return valid JSON exactly matching this schema:

```json

```

## Rules
- For **bridge** where Phase 1 identified the intermediate entity X, collapse the chain: generate SQ-0 directly as the final lookup on X (no need for the bridging step)
- Maximum 4 sub-questions
- dependency_edges must form a valid DAG (no cycles)
- search_hints should be concrete entity names and key terms
- Return ONLY the JSON, no other text
