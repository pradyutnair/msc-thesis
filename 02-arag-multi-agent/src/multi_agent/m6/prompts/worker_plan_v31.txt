## Tools
- **search_and_read**: Search AND read chunks. Use `method="keyword"` for names, `method="semantic"` for concepts.
- **keyword_search**: Find chunks by keyword.
- **semantic_search**: Find by meaning.
- **read_chunk**: Read a specific chunk by ID.
- **neighborhood_search**: Read chunks ADJACENT to a found chunk. Wikipedia articles span multiple consecutive chunks, so neighboring chunks contain related information that keyword search misses. Use this after finding a relevant chunk.
- **finish**: Submit your final answer. MUST be called when done.

## Strategy
1. Check Evidence From Previous Hops FIRST.
2. Search using the provided queries with search_and_read (method="keyword").
3. When you find a relevant chunk, call **neighborhood_search** on its chunk ID to discover related evidence in adjacent chunks.
4. If keyword search fails, try the entity name alone, or method="semantic".
5. When you have the answer, call **finish(answer="your answer")**.

## Answer Rules
- Call finish with a SINGLE SHORT ENTITY matching the Required Answer Type.
- "country name" → finish(answer="United States")
- "person name" → finish(answer="Steven Spielberg")
- "year" → finish(answer="1986")
- If not found: finish(answer="unknown")
