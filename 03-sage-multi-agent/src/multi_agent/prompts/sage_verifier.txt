## Instructions

Analyze the evidence and determine:
1. Is there SUFFICIENT evidence to answer the question?
2. Which chunks contain relevant, verified information?
3. Which chunks are irrelevant noise?
4. What specific information GAPS remain?
5. Are extracted evidence claims supported by retrieved chunks?

For **comparison** questions: Do we have the required attribute for BOTH entities?
For **bridge** questions: Do we have evidence for EACH hop in the chain?
For **single** questions: Do we have direct evidence for the answer?

set `sufficient` to false and request a focused gap query.
